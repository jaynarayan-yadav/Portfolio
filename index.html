02 — Flagship Project

DataEngine: the cleaner that asks first.

Repository
github ↗
Stack
Python • pandas • scikit-learn • pytest • CLI
Tests
67+ passing pytest units
Interface
Python API + Interactive CLI

Every cleaner I tried mutated data silently and leaked test statistics into training. DataEngine diagnoses first, then waits at a proceed / abort / customize gate — abort returns the original DataFrame hash-verified and untouched. Try all three paths below.

dataengine — demo_dataset.csv

Strict fit(X_train) / transform(X_test) contract — test statistics never touch the pipeline. Serialises to joblib for production.

pip install git+https://github.com/jaynarayan-yadav/DataEngine.git engine = DataEngine(interactive=True) engine.fit(X_train) # stats frozen on train only clean_test = engine.transform(X_test) # zero leakage engine.save("pipeline.joblib")
